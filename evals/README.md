# Evals

A reproducible transcript of an AI agent operating through Keyring.

## `transcript.md`

Generated by `scripts/demo-agent.mjs`. Every entry is a real MCP tool call
against a deployed NEAR testnet contract, and the payment is a real Base
Sepolia transaction. Nothing is mocked, stubbed or hand-edited.

The workflow follows CLAUDE.md §13:

| Step | What it shows |
|---|---|
| 0 | The tool surface the agent is given — and what is deliberately absent from it |
| 1 | The agent discovers its derived address and its policy |
| 2 | It simulates before spending (a view: no budget consumed, nothing recorded) |
| 3 | An allowed payment, signed by the MPC network and included in a Base Sepolia block |
| 4 | A disallowed destination refused, with the rule that refused it |
| 5 | Inflated gas parameters caught by the fee cap |
| 6 | The owner revokes the agent — using the owner's key, not an MCP tool |
| 7 | The revoked agent's next request fails |
| 8 | The audit history showing every decision |

Step 6 is the point worth dwelling on: revocation happens through the SDK with
the owner's key, because **there is no MCP tool for it**. The agent cannot
revoke itself, re-enable itself, change its own policy, or raise its own caps,
because no tool exposing those actions exists for it to be tricked into
calling.

Step 4 is the other one: the refusal carries a machine-readable code, the rule
that produced it, the configured limit and the observed value. A refusal is a
product feature, not an error to hide.

## Reproducing it

```bash
export KEYRING_CONTRACT_ID=keyring-gated-1794298589.testnet
export KEYRING_OWNER_ID=$KEYRING_CONTRACT_ID
export AGENT_ACCOUNT_ID=<the agent's NEAR account>
export AGENT_PRIVATE_KEY=<that account's key>
export AGENT_PUBLIC_KEY=<the registered agent public key>
export OWNER_PRIVATE_KEY=<the owner account's key>

pnpm -r build
node scripts/demo-agent.mjs
```

The run ends with the agent revoked, so a re-run needs it registered again.
Re-registering with the same label and key yields the same derived address, so
the funded Base Sepolia address does not change.

The payment needs the derived address to hold a little Base Sepolia ETH. Read
it with the `get_addresses` tool, or:

```bash
node -e "import('./packages/sdk/dist/index.js').then(async m => \
  console.log((await m.deriveEvmAddress({ \
    path: 'keyring-v1,keyring-gated-1794298589.testnet,agent-one,base-sepolia', \
    predecessor: 'keyring-gated-1794298589.testnet' })).address))"
```
