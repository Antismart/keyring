Overview

Live state read from the Keyring contract on NEAR testnet. Every figure below is computed from contract data, never cached or estimated.

policy Where enforcement happens

Policy lives in a NEAR smart contract. An agent asks for a transfer; the contract evaluates it, and only then builds the transaction itself and calls NEAR Chain Signatures. Execution settles on the destination chain — Base Sepolia or Bitcoin testnet4 — never on NEAR. The agent holds no key and never supplies calldata, a preimage or a hash.

Owner actions

This console holds no key and signs nothing. It composes the exact command for you to run, so the owner's key never leaves your machine.

shield
Never paste a private key into a web page. Keyring registers and policy-gates public keys only. Owner authority comes from predecessor_account_id() on the contract call, so every action below must be signed by the owner account itself.
